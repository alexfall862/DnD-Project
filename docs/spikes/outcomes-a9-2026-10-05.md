# Outcomes on A9 — 2026-10-05

These runs check that the 10d changes ("Outcomes change the world", `DECISIONS.md`) work with
GLM-4.5-Air. `tests/eval/test_outcomes_a9.py` replays, on A9 through the full HTTP API at the
Frostbridge gate, the lines that failed in play session 2 (campaign `879ea872`). Every check the
game called for was rolled.

## The lines and what happened (run 3, after the fixes)

## Problems found, and fixed

| Run | Problem | Fix |
|---|---|---|
| 1 | GLM put `reveal_feature` among the effect steps, so the whole ruling was rejected and the search "found nothing" | Consequence kinds written as effect steps move to their branch's `consequences`. Unknown primitives are still refused |
| 1 | The threat was read as plain speech, and the described line was spoken whole | Interpreter rule: a demand backed by a consequence is intimidate. `described_speech` keeps only the line |
| 2 | Each consequence was applied twice (GLM wrote them in both places) | Proposals are deduplicated by kind and subject |
| 2 | "We go into town" became a move to the gate zone (a no-op) | When the words speak of going somewhere, a move to where the character stands gets one more interpretation, pointed at travel |
| 2 | The narrator kept quoting the merchant's earlier line | Quotes are found in the whole narration before sentences are split, so "Just my luck. First the…" counts as one quote and is cut |
| 3 | GLM copied the prompt's example ref `s_1a2b3c` (rejected correctly: there was no obstacle) | The example now uses a placeholder, and the prompt says to use refs only as listed |
| 3 | An NPC's own consequence read "You refuses…" | Consequence text uses the names the player knows |

## Timings
