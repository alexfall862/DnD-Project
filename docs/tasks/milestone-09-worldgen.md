# Milestone 09 — Campaign Generation

## Goal
Generate new structured campaigns through staged World Author calls.

## Read
`architecture/04-campaign-generation.md` (all); `architecture/03-ai-orchestration.md` §27–§28; `specifications/ai-contracts.md` §13; `specifications/api-contracts.md` §6; `specifications/database-schema.md` §13, §17; `testing/testing-strategy.md` §17.

## Implement
CampaignBrief; GenerationRun/GenerationStage; premise, metaphysics, macro geography, cultures, politics, factions, history, current conflicts, secrets, starting region/settlement/NPCs/opportunities/party/opening scene; latent/established canon; stage regeneration/dependency invalidation; contradiction/rules validation.

## Invariants
Established canon cannot be contradicted. Mystery truth precedes clues. Distant content stays shallow. Generated mechanics use registered primitives.

## Tests
Deterministic FakeModel generation, stage reroll, dependency invalidation, contradiction rejection, mystery/clue validation, generated mechanics validation.

## Acceptance
A non-Frostbridge campaign can be generated and entered as a playable opening scene.

### Follow-ups (09b) — done 2026-10-04

The deferrals above are now built:
- **Genre modules** (`rulesets/core_adventure/modules/`: fantasy, horror, survival, sci-fi):
  chosen from the brief's genres at `create_run`, recorded in `campaign.settings.genre_modules`
  and used by validation, building, play and worker jobs (`RulesEngine.for_campaign`).
- **Custom / imported worlds** (`POST /campaigns/{id}/imports`; `app/worldgen/importer.py`):
  structured JSON validated directly; text/Markdown read in ≤ 8 bounded chunks; the import is
  established canon the pipeline extends; imported character sheets join the party.
- **Guided creation** (`GET/POST /campaigns/{id}/brief/guided`; `app/worldgen/guided.py`;
  `brief_interviewer` role): ≤ 8 answers, each a validated brief patch.
- **Frostbridge §23 artifact** generated by the World Author when a provider is given
  (`make seed-demo ARGS="--generate-artifact"`), the fixed definition as fallback.
- **Real-model runs:** the full 18-stage pipeline completes on A9 and the world starts; 23 runs
  and the fixes they forced are in `docs/spikes/worldgen-a9-2026-10-04.md`.

Tests added: `tests/unit/test_genre_modules.py`, `tests/integration/test_worldgen_import.py`,
`tests/integration/test_worldgen_guided.py`, a horror-campaign test, the artifact-slot test,
the continuation test, the salvage/truncation/timeout unit tests and one regression test per

### Itemized stages (09c) — done 2026-10-04

The heavy stages (secrets, settlement, NPCs, opportunities, party) run as an outline call
plus one call per item, with per-item retries, kept good items, persisted progress and resume
(`app/worldgen/itemized.py`, migration 0015; `DECISIONS.md`, "Itemized generation stages").
Tests: `tests/unit/test_worldgen_itemized.py`; in `tests/integration/test_worldgen.py`, a bad
NPC sheet retried alone and resumed on rerun, the clue shortfall sent back to the items
without clues, call sequences for the full run and the reroll; the continuation test now uses
a plain stage. The A9 eval resumes with `WORLDGEN_A9_RESUME=<run id>`.

On A9 the first itemized run stopped at one opportunity, and three good items were kept. The
resume asked only for that item, then finished party and opening. Five fixes followed from
the run, each with a regression test, and the generated world starts. Numbers are in the
spike report.
